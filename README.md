# press-check

한국어 기사 원고(제목·부제·본문·사진 설명)를 발행 전에 검토해, 언론분쟁 쟁점이 될 수 있는 구체적 표현과 확인 사항을 찾고 기사 취지를 유지하는 최소 수정안을 제안하는 Claude Code 플러그인입니다. 기사 분석은 호스트 모델이 하고, 로컬 MCP 서버는 원문 위치·해시·근거 인용·수정안 검사만 합니다.

> **법률 자문이 아닙니다.** 검토 보조 도구입니다. 별(★)은 검토 우선순위이며 분쟁·패소 확률이 아닙니다. 검증 범위와 수집 자료의 한계는 [플러그인 README의 '한계와 사용 범위'](plugins/press-check/README.md#한계와-사용-범위)를 읽으세요.

**처음 쓰시는 분은 [docs/USER_GUIDE_KO.md](docs/USER_GUIDE_KO.md)를 먼저 읽으세요.** GitHub, 플러그인, 터미널에 익숙하지 않은 기자·데스크를 위한 설치와 첫 사용 안내입니다.

- Claude Code 입력창에서 `/plugin marketplace add JINKOO1991/press-check`, `/plugin install press-check@press-check` 순서로 설치합니다.
- 원고를 붙여 넣고 "검토해 줘"라고 하면 문제 요소·★ 검토 필요도·사유·추천 수정안 표가 나옵니다.
- 원고는 호스트 모델에 전송될 수 있으며, 개인정보·보안 안내는 안내 문서 5절에 있습니다.
- 검토 뒤 수정안을 반영한 변경본이 대화에 자동으로 나옵니다. ★2 이상이고 서버 검사에 걸리지 않은 수정안만 적용하고 나머지는 제안으로 둡니다. 원본 파일은 바꾸지 않습니다.
- 판례와 헌법재판소 결정을 근거로 쓰면 "법원 판결, 법제처 국가법령정보센터 제공" 또는 "헌법재판소 결정, 법제처 국가법령정보센터 제공" 출처 문구가 함께 나옵니다. 인용 표시 동작은 [docs/CITATION_RULES.md](docs/CITATION_RULES.md)에 있으며 법률 판단이 아닙니다.

## 구성

- `plugins/press-check/`: 플러그인 본체(MCP 서버, 스킬, 수집·색인 엔진). 설치와 사용법은 [플러그인 README](plugins/press-check/README.md)에 있습니다.
- `.claude-plugin/`: 마켓플레이스 정의.
- 현재 저장소에는 판례·헌법재판소 결정·심의·정정 자료 등 어떤 코퍼스도 들어 있지 않습니다. 설치만으로는 근거 검색이 오류를 돌려주며, 각자 수집 CLI로 로컬 색인을 만들어야 합니다(플러그인 README의 '코퍼스 만들기').
- 판례와 헌법재판소 결정은 법제처 이용안내에 따라 재배포가 허용되고 조건은 출처 표기입니다. 언론중재위원회·인터넷선거보도심의위원회 자료는 이용 허락을 문의 중이어서 코퍼스를 저장소에 포함하지 않습니다(2026-11-06 기준).
