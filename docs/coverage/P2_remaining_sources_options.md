작성 2026-10-10. 읽기 전용 조사(manifest `mode=ro`, query_only). 수신·구조화 CLI, DeepSeek, 네트워크 호출 없음. 결정은 사용자 몫이다. 이 문서는 선택지와 근거 수치만 적는다.

## 0. 권리 상태 (맨 앞 확인 사항)

세 소스 모두 장부 `rights`(source 범위)에서 `external_api=allowed`, `create_derivatives=allowed`, `store_raw=allowed`다. 문서 단위 override는 0건이다(rights_ledger.json `document_overrides` 비어 있음, `rights` 테이블 document 행 0). 그러나 근거는 사용자 결정 UDEC-5(2026-10-08)이고 `review_status`는 세 소스 모두 `pending`이다. 재배포·미세조정은 `permission_required`다. PAC·IENDC 이용 문의 초안(docs/outreach/)은 발송 전이다(STATUS: 발송은 사용자 몫). 따라서 허용은 확정된 권리가 아니라 사용자 결정에 따른 잠정 기록이다. 어느 옵션이든 '외부 API 처리 허용' 자체는 충족하나, 문의 회신이 거절이면 결과물 전체(색인 포함)가 영향을 받는다. IENDC는 공공누리 표시가 없는 자료에 사전 협의를 요청하는 기관이다(DECISIONS UDEC-5 근거란).

- IENDC: 인용은 85.03%로 통과선 위, 격리만 25.4%. 표본이 4개 첨부라 판정이 한 문서(`1949#1`)에 좌우된다. 표본이 늘면 달라질 수 있다.
