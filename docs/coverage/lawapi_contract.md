# 법제처 판례 목록 API 계약 (lawapi 어댑터)

확인일 2026-10-08. 출처: 공식 가이드 `https://open.law.go.kr/LSO/openApi/guideResult.do?htmlName=precListGuide` 원문 HTML을 어댑터와 같은 HTTP 클라이언트로 받아 태그를 제거하고 옮겼다(요약기를 거치지 않음). 아래 "가이드 원문" 열은 그 텍스트다. "실측"은 2026-10-08 실제 호출 결과다.

## 요청

가이드 요청 URL: `http://www.law.go.kr/DRF/lawSearch.do?target=prec` (가이드는 http로 표기). 실측: **https도 같은 응답을 준다**(`https://www.law.go.kr/DRF/lawSearch.do`). 어댑터는 https만 쓴다.

| 요청변수 | 값 | 가이드 원문 설명 | 어댑터 사용 |
|---|---|---|---|
| OC | string(필수) | 신청한 API인증값 | `with_oc=True`로 클라이언트가 주입. URL·장부·캐시에는 `OC=[MASKED]` |
| target | string : prec(필수) | 서비스 대상 | `prec` |
| type | char(필수) | 출력 형태 : HTML/XML/JSON | `JSON` (XML도 같은 필드를 줌) |
| search | int | 검색범위 (기본 : 1 판례명) 2 : 본문검색 | `2` |
| query | string | 검색범위에서 검색을 원하는 질의(검색 결과 리스트) (정확한 검색을 위한 문자열 검색 query="자동차") | 검색어 사전 27개, 따옴표 없이 |
| display | int | 검색된 결과 개수 (default=20 max=100) | 100 (게이트는 20) |
| page | int | 검색 결과 페이지 (default=1) | 1부터 |
| org | string | 법원종류 (대법원:400201, 하위법원:400202) | `400201` |
| curt | string | 법원명 (대법원, 서울고등법원, 광주지법, 인천지방법원) | 미사용 |
| JO | string | 참조법령명(형법, 민법 등) | 미사용 |
| gana | string | 사전식 검색(ga,na,da…,etc) | 미사용 |
| sort | string | 정렬옵션 lasc : 사건명 오름차순 / ldes : 사건명 내림차순 / dasc : 선고일자 오름차순 / ddes : 선고일자 내림차순(생략시 기본) / nasc : 법원명 오름차순 / ndes : 법원명 내림차순 | `dasc` |
| date | int | 판례 선고일자 | 미사용 |
| prncYd | string | 선고일자 검색(20090101~20090130) | 20,000건 초과 질의의 연 단위 슬라이스 |
| nb | string | 판례 사건번호 | 미사용(진단용 탐침만) |
| datSrcNm | string | 데이터출처명 (국세법령정보시스템, 근로복지공단산재판례, 대법원) | 미사용 |
| popYn | string | 상세화면 팝업창 여부(팝업창으로 띄우고 싶을 때만 'popYn=Y') | 미사용 |

## 응답 필드 (가이드 원문)

target, 공포번호, 키워드(검색어), section(검색범위 `EvtNm:판례명/bdyText:본문`), totalCnt(검색결과갯수), page(출력페이지), prec id(검색결과번호), 판례일련번호, 사건명, 사건번호, 선고일자, 법원명, 법원종류코드(대법원:400201, 하위법원:400202), 사건종류명, 사건종류코드, 판결유형, 선고, 데이터출처명, 판례상세링크.

## 이용조건·호출 제한

가이드 페이지에는 이용조건이나 호출 제한 문구가 없다. 페이지 하단 문구는 다음뿐이다: "사용신청 및 이용문의 : 02-2109-6446". 호출 제한 수치는 확인하지 못했다(2초 간격·동시성 1로 1,171쪽을 호출했고 429·5xx·오류 응답은 0건). 이용 허락 범위는 사용자 결정 UDEC-5와 별개로 법제처에 문의해야 확정된다(`docs/DECISIONS.md`).

## 실측으로 확인한 응답 형태 (가이드와 다른 점 포함)

- JSON 봉투는 `{"PrecSearch": {키워드, page, target, prec, totalCnt, section}}`. `totalCnt`·`page`는 **문자열**이다. `prec`은 0건이면 키가 없고, 여러 건이면 배열이다(1건일 때 객체일 가능성에 대비해 파서가 처리하며 실측은 하지 못했다).
- `section` 값은 가이드의 `EvtNm`이 아니라 `evtNm`(사건명 검색)·`bdyText`(본문검색)로 온다.
- `법원종류코드`는 모든 행에서 빈 문자열이다. `org=400201`이 적용됐는지 이 필드로는 확인할 수 없다.
- **`org=400201` 응답에는 `데이터출처명`이 다른 행이 섞인다.** 1,171쪽 수집 결과(73,237건)를 `extra.source_scope`로 나눴다: `supreme` 62,294(법원명·출처 모두 대법원, 사건부호 다·도·누·두·후·마 등) / `supreme_via_other_source` 1,295(법원명 대법원, 출처 지방세법령정보시스템, 사건부호 두·누·다가 대부분이고 `supreme`와 사건번호+선고일이 겹치는 것은 27건뿐) / `lower_court_in_supreme_source` 13(출처 대법원, 법원명이 서울고등법원 등 하급심, 사건부호 가합·구합·노 등) / `non_court_source` 9,635(법원명 빔; 국세법령정보시스템 6,248과 근로복지공단산재판례 3,387, 사건번호 없음). 법원 판결이 아닌 행까지 버리지 않고 표시만 한다. 대법원 판결 분석에는 `supreme`와 `supreme_via_other_source`를 쓰되 전자의 법원명·사건부호를 P2에서 본문으로 재확인한다.
- 선고일자 이상값: `0001.01.01` 자리표시 3,387건(전부 근로복지공단산재판례 출처, 사건번호도 없음). 원문은 `extra.raw_date`에 두고 decision_date·year는 비운다. 전체 대법원 질의(query 없음)에서 `prncYd=00010101~18991231`은 3,426건이다.
- `prncYd`는 `YYYYMMDD~YYYYMMDD` 닫힌 구간이며 `00010101~19491231`, `20270101~99991231`도 받는다. 같은 날 하루 구간은 0건일 수 있다.
- 같은 사건번호에 `판례일련번호`가 둘인 경우가 있다(예: 80도306, 사건명 표기만 다름). doc_id는 일련번호 기준이라 합치지 않는다.
- 공식 상세링크 필드는 `/DRF/lawService.do?OC=...&target=prec&ID=<일련번호>&type=HTML&mobileYn=` 형태로 OC를 되울린다. 클라이언트가 응답 본문에서 `OC=` 값을 마스킹한 뒤 캐시하고, 어댑터는 detail_url에서 OC 쌍을 제거해 저장한다. canonical_url은 `https://www.law.go.kr/LSW/precInfoP.do?precSeq=<일련번호>`.
- 본문검색 질의 형태: 따옴표 없는 다어절 질의는 단어별 포함으로 넓게 잡힌다. 사전에 쓴 형태(따옴표 없음)와 따옴표 구문 질의의 건수(대법원 org, search=2):

| 검색어 | 따옴표 없음(수집한 값) | 따옴표 구문 질의(수집하지 않음) |
|---|---|---|
| 공공의 이익 | 1,171 | 330 |
| 상당한 이유 | 21,444 | 588 |
| 사실의 적시 | 1,853 | 180 |

  "상당한 이유"는 따옴표 없는 형태가 2만 건 기준을 넘어 연 단위 슬라이스로 수집했다. 좁은 형태가 필요하면 후속 단계에서 따옴표 질의를 추가한다.
