## 구현
- 같은 본문 중복: 제외 필터 통과 chunk 중 min(created_at, chunk_id) 하나만 남긴다. 제거된 chunk는 `passage_alias`(alias_id, source_id, 남은 passage_id, url·위치·권위·기준일·사건번호)에 보존하고 snapshot 해시에 넣는다. `get_passage(옛 source_id, 옛 id)`는 정본 본문에 옛 passage 자신의 메타를 붙여 돌려주므로 증거 대조(url·locator·authority_type·기준일)가 그대로 통과한다. 검색에는 별칭이 나오지 않는다.
- `passages.chunk_kind`(case/list/text). 목록 장 강등과 평가 하네스 `no_demote`가 이 열을 읽는다. 목록 장 수 3,421 = 이전 술어 4,705 − 중복 제거분 1,284.
- `INDEX_FORMAT` pdr-index-4. pdr-index-3 색인도 읽는다(열·별칭 표 없음은 이전 술어, 되돌리기 가능). 빌드는 기본 폴더가 아닌 별도 폴더에서 한 뒤 파일 이동(sha256 동일)과 `CURRENT` 갱신으로 전환했다(기본 폴더 빌드는 `KEEP_INDEXES=3` 정리로 기존 snapshot을 지울 수 있어서).
- 테스트: 새 2개(tests/engine/test_eng_index_dedup.py), 기존 test_cx1_9는 본문이 같은 합성 201건이 하나로 합쳐져 본문에 순번을 붙였다. 전체 1,180 passed·1 xfailed(기준선 1,178).
