# 인터넷선거보도심의위원회 자료 이용 문의 (초안, 발송 전)

상태: 초안. 발송은 사용자가 한다. 대괄호 항목은 발송 전에 채운다.

수신: 인터넷선거보도심의위원회 [담당 부서·담당자]
발신: [성명·소속], [이메일], [전화]
일자: [발송일]

## 1. 문의 목적

국내 언론인이 선거 관련 기사를 쓸 때 심의 사례를 미리 참고하도록 돕는 무료 공개 플러그인을 만들고 있습니다. 비영리이며 유료화 계획이 없습니다. 법적 판단이나 심의 결과를 대신하지 않고, 검토가 필요한 지점을 알려 주는 보조 도구입니다.

귀 위원회 홈페이지(www.iendc.go.kr)의 심의결과 내역 게시판에 공개된 게시물과 첨부 PDF를 아래 방식으로 처리하고 있습니다. 홈페이지 저작권정책을 확인했으며, 공공누리 표시가 없는 자료는 사전 협의가 필요하다고 이해했습니다. 이에 협의를 요청드립니다.

## 2. 현재 처리 방식

- 접근: robots.txt를 확인하고 호스트당 2초 이상 간격으로 공개 게시판만 요청합니다. 로그인이 필요한 영역과 차단된 경로는 요청하지 않습니다.
- 보관: 게시물 목록, 제목, 등록일, 첨부 PDF 주소와 파일 크기를 내부 장부에 기록했습니다. PDF 원문 내려받기와 본문 추출은 이용 가능 여부를 정리하는 대로 진행합니다.
- 처리: 로컬에 보관한 문서에서 심의 대상, 조치 내용, 근거 조항을 구조화해 내부 색인을 만들 계획입니다. 구조화에 외부 언어모델 API를 쓸 수 있습니다.
- 재배포: 하지 않습니다. 원문 PDF와 이를 가공한 결과물은 플러그인과 함께 배포하지 않습니다.
- 현재 권리 기록: 내부 처리는 허용으로, 원문·파생물 재배포와 모델 미세조정은 "허락 필요"로 기록해 두었습니다. 이 기록은 제가 내린 잠정 판단이며 귀 위원회의 허락을 대신하지 않습니다.
- 참고: 일부 게시물은 HWP 파일만 있어 내려받기 방식 때문에 목록 확인까지만 했습니다.

## 3. 이용 허락 요청 범위

각 항목에 대해 가능, 조건부 가능, 불가 중 하나로 회신해 주시면 됩니다.

| 번호 | 이용 방식 | 설명 | 회신 |
|---|---|---|---|
| 1 | 내부 색인 | 내려받은 문서를 제 컴퓨터에서 검색용 색인으로 만듭니다 | |
| 2 | 외부 API 구조화 | 문서 본문을 외부 언어모델 API에 보내 심의 대상·조치 내용 등을 추출합니다 | |
| 3 | 요약·발췌 표시 | 사용자에게 출처(게시물명·링크)와 함께 짧은 요약이나 짧은 발췌를 보여 줍니다 | |
| 4 | 원문 재배포 | 원문 PDF나 전문을 플러그인 사용자에게 제공합니다. 현재는 하지 않으며 허락 전에는 하지 않습니다 | |
| 5 | 가공물 재배포 | 구조화한 결과를 플러그인과 함께 배포합니다 | |
| 6 | 모델 미세조정 | 문서를 모델 학습 자료로 씁니다. 계획에 없습니다 | |

## 4. 추가로 여쭙고 싶은 점

- 사전 협의에 필요한 절차나 서류가 있다면 안내해 주십시오.
- 공공누리 유형이 정해져 있는 자료가 있는지, 있다면 어떤 자료인지 알려 주시면 그에 맞추겠습니다.
- 중단을 원하시면 즉시 요청을 멈추고 보관분을 정리하겠습니다.
